# Preferencias de trabajo

- El proyecto de aplicación es esta carpeta campus-loop. Los documentos académicos de las carpetas hermanas no se publican en GitHub.
- Mantener una interfaz minimalista; conservar las funciones exigidas por los requisitos y no mostrar cifras o promesas sin respaldo.
- El usuario autorizó hacer commit y push a origin/main (Yayackie/Plataforma_intercambio) de los cambios terminados y revisados. Comprobar el destino y los cambios antes de cada push; informar límites de validación.
- Nunca publicar secretos ni datos personales de las cuentas originales. Usar datos ficticios.
- La rama local backup/local-history-before-github-2026-10-10 conserva historia antigua con datos originales: no publicarla, no fusionarla con main y no usar push --all ni --mirror.
- La carpeta tmp/campus-loop-github del directorio padre fue una copia de publicación inicial. Los cambios actuales y próximos se realizan y publican desde campus-loop.
